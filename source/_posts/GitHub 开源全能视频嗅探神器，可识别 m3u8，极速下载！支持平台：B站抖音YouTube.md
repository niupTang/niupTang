# MediaGo 视频嗅探神器使用指南
![](https://mmbiz.qpic.cn/mmbiz_png/p1ESIQQvfrQJXewsyRRZ9dMzCcotyCKJOXibE0xq2SCGL68Gjg0hDl8OTZ1HYKbwIKEOM0vf6HVAsYb8aLru4zA/640?wx_fmt=png&from=appmsg)

## 🚀 工具核心功能
- • **智能嗅探**：内置浏览器自动识别网页视频资源，无需抓包技术

- • **批量下载**：支持多任务并发下载，充分利用网络带宽

- • **跨端兼容**：下载视频支持PC/手机双端播放（支持MP4/MKV/FLV格式）

- • **流媒体解析**：完美破解m3u8等流媒体格式加密

- • **云部署**：提供Docker容器化部署方案

## 📦 安装指南
### 基础安装
- 1. 访问官方网站 或 GitHub Releases

- 2. 选择对应系统的安装包：

- • Windows: `MediaGo_Win_x64_v3.0.0.exe`

- • macOS: `MediaGo_Mac_Universal_v3.0.0.dmg`

- • Linux: `MediaGo_Linux_x86_64_v3.0.0.AppImage`

### 自动嗅探模式
- 1. 点击「素材提取」按钮

- 2. 粘贴视频页面URL（支持平台：B站/抖音/YouTube）

- ![](https://mmbiz.qpic.cn/mmbiz_png/p1ESIQQvfrQJXewsyRRZ9dMzCcotyCKJ2s3AZu4ZBYL10nvLg0HJPttCQqicnWP74a9wdxqNAO86t9wzCFOzmibQ/640?wx_fmt=png&from=appmsg)

- 3. 等待嗅探完成（进度条显示100%）

- ![](https://mmbiz.qpic.cn/mmbiz_png/p1ESIQQvfrQJXewsyRRZ9dMzCcotyCKJG8o3hyvicTib8jXpyetXnX7dhJFZxWQXvATKzvZCsicS0JTIGC1ryYtEQ/640?wx_fmt=png&from=appmsg)

- 4. 勾选目标文件 → 点击「批量下载」

- 

### 移动端播放
- 1. PC端下载完成后点击「生成二维码」

- 2. 使用手机相机扫描二维码

- 3. 选择视频播放器打开
